# Phase 7 – Quality assurance

Status: 2026-10-29. Tests, network check, security review, licences, F-Droid check,
measurements – and what was found and fixed on the way.

## Decisions during the phase

- **Android 14+ only** (`minSdk 34`): the versions that still get security updates from
  Google ([Android Security Bulletin, October 2026](https://source.android.com/docs/security/bulletin/2026/2026-10-01):
  14, 15, 16, 17). Compatibility code for older versions was removed; tests run only on
  supported versions (oldest: Android 14 emulator, newest: Android 17 on a Pixel 10).
- **Material 3 Expressive** (1.5.0-beta02) instead of the stable 1.4.0: expressive theme and
  motion, loading indicators, wavy progress, morphing button shapes, connected button group,
  short navigation bar / wide navigation rail.

## Network check (Android 14 emulator, no Google services)

All traffic of the emulator went through `tools/host-log-proxy.py`, which logs the target of
every connection and decrypts nothing. Each step was marked in the log; the emulator alone
(no app) defines the baseline.

| Phase | Connections | Belongs to |
|---|---|---|
| Baseline, app not installed | `connectivitycheck.gstatic.com`, Google IPs, DNS over TLS | Android itself |
| Start, tabs, rubric, search | `planetfoss.net` (46.225.198.172, images), fixture server | app – content |
| Tracker protection switched on | `easylist.to` (104.21.60.31, Cloudflare) | app – filter lists |
| Notifications on, check | fixture server (connection reused) | app – API |
| Article in the internal browser | noted.lol and the CDNs/fonts that page loads | the site the user opened |
| Article with Custom Tab mode on AOSP | same, but from “WebView Browser Tester” | external app (no Custom Tabs browser → chooser fallback) |
| 3 minutes in the background, notifications and tracker protection on | **none** | – |

No connection to any analytics, crash-report or ad service, no Google service from the app,
nothing the documentation does not list (README, `docs/05-browser.md`, `docs/06-adblock.md`).
With the real API the content host is planetfoss.net only.

| Check | Result |
|---|---|
| Exported components (release manifest) | `MainActivity` (launcher, `planetfoss://` VIEW, not BROWSABLE); WorkManager `SystemJobService` (`BIND_JOB_SERVICE`); WorkManager diagnostics and ProfileInstaller receivers (`DUMP`, shell only) |

## Licences and F-Droid

- `LICENSES.md`, generated by `tools/licenses.py`: 213 libraries in the release APK, all
  Apache-2.0 except one BSD-3-Clause; the script fails on a missing or unknown licence.
- `fdroid scanner` (fdroidserver 2.4.5) on the source (metadata draft with the local Git
  repo): **0 problems**. On the release APK (`-e`): exit code 0 – no known non-free classes,
  no extra signing blocks.
- Reproducible: two clean release builds (`clean :app:assembleRelease --no-build-cache`) are
  byte-identical (SHA-256 `234cf687…f067`, before the Expressive switch).

## Found and fixed in this phase

| Finding | Fix |
|---|---|
| A denied notification permission left the switch silently off (Android 14) | settings show “Android did not allow notifications” and a button to Android's settings |
| Filter rules took 45 MB of Java heap | plain `||host^` rules as strings, shared empty sets: 14 MB |
| Third party approximated without a public-suffix list | OkHttp's Public Suffix List, once per request |
| Exported activity accepted Navigation extras | only `planetfoss://` links pass; browser loads http(s) only |
| Unused foreground service and permission from WorkManager | removed from the manifest |

## Device check, Pixel 10 (2026-10-30)

- **Material 3 Expressive:** Latest, Supernovas (full, compact, comet cards), Rubrics, Saved,
  settings, card menu and the internal browser look as on the emulator. Found: the time in
  compact supernova cards was cut beside the image; the internal browser's description still
  named an older feature. Both fixed.
- **Doze (simulated):** `dumpsys battery unplug` + `deviceidle force-idle`: the supernova check
  waits (`DEVICE_NOT_DOZING` unsatisfied); stepped to `IDLE_MAINTENANCE` the constraint is met
  again and only the 30-minute timing remains. Undone afterwards (`unforce`, `battery reset`).
  Not covered: a real night with the phone unplugged and an actual new supernova.
- **Live counting:** article opens from the app arrive on planetfoss.net (2 on 30.10.).
- **TalkBack (accessibility tree):** a remote walk-through with TalkBack gestures does not work
  (injected swipes move the focus only now and then). Instead the tree TalkBack reads was dumped
  (`uiautomator dump`) on Latest, Supernovas, Rubrics, Saved and Settings, navigated by TalkBack
  double taps: every card, button, chip and switch has a label; reports in supernova cards read
  “title, source”. Fixed: badges read the star sign and capitals (“✦ SUPERNOVA”) – now the plain
  word; supernova chips did not say they are one – now “Supernova” as state (Compose test).
  Not covered: how it sounds and flows when listening; screens below the fold.
